## 🧠 Under The Hood: How The Proxy Works

Streaming sites are constantly taken down by ISPs and copyright holders. The domains change every few weeks. To combat this, our community maintains a **Dynamic Proxy**.

We use Cloudflare Workers to create a serverless proxy. When you visit your custom proxy URL, the Worker fetches the content from the original 111Movies server on your behalf. Because the request is coming from Cloudflare's IP addresses, your ISP cannot see what you are accessing.

The Worker also injects a custom CSS file that hides ad banners and disables the malicious pop-up scripts. The result is a clean, ad-free streaming experience that works on any device with a web browser.

## ⚙️ How To Set It Up

You can use the standard mirrors immediately, or follow these steps to deploy your own private proxy.

```bash
# Step 1: Choose a working mirror from the releases page
# Step 2: Install uBlock Origin in your browser
# Step 3: Import the custom filter list provided in the "filters/" folder
# Step 4: (Optional) Deploy the Cloudflare Worker using the script in "proxy/"
```

Once the filter list is active, you will notice that the site loads significantly faster. All the distracting ads are gone, leaving you with just the video player and the content you actually want to watch.
